# Agent Navigation Contract

Start with `conductor/index.md`, then load only the selected track's specification, plan, metadata, dependencies, and bounded context pack. Treat `conductor/product-guidelines.md` as the safety and content boundary and `conductor/workflow.md` as the delivery contract.

Do not infer completion from checkboxes, issue state, or a green focused test. Preserve private data, credentials, source rights, human authority, licence choices, external actions, and release decisions as explicit gates. Keep the portable skill core client-neutral; client behaviour belongs in adapters.

Repository engineering, research and closure reviews use agent panels, not
independent human reviewers. Follow the standing decisions in
`conductor/decisions/20260830-001-legacy-agent-review.md` and
`conductor/decisions/20260830-002-prospective-agent-study.md`. Do not re-request
approved review, routine implementation, rework or readiness-only fallback.
Before escalating, check existing authority; ask only for the genuinely new
scope or reserved action, once per stable decision. Historical human-comparator
data and clinical/legal/organisational authority are not agent review duties.
