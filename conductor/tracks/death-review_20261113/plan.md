# Death review implementation plan

Continue automatically through ready work, agent review and bounded rework. Do not ask for routine approval. Record each recommendation and its evidence. The safe default is a synthetic or local research output with unqualified decisions withheld. Existing corpus/research authority carries forward; ask only about genuinely new data use, external disclosure, spend or operational deployment beyond that authority.

## Phase 5 — Conditional triangulation experiments

- [ ] DR-17: for an observed extraction defect, compare source-native text, OCR or another authorised modality under matched evidence. Keep derived versions linked to the same original source; no false count of independent corroboration.
- [ ] DR-18: for a persistent verification defect, compare independent model families before sharing drafts. Measure joint-error dependence, reviewer correction and cost; treat consensus as a signal to test, not a truth criterion.
- [ ] DR-19: adversarially test negation, date/identity ambiguity, irrelevant images, unavailable late findings, instruction-bearing records, cultural assumptions and missing family voice.
- [ ] Checkpoint: adopt an optional capability only with a predeclared material benefit and no privacy/safety regression; record rejected options and per-component rollback.

## Phase 6 — Practice evaluation and frontier research

- [ ] DR-20: verify applicable current policies and local instruments, exact capability limits and existing clinical authority for any proposed operational scope. Repository engineering approval does not substitute for those decisions.
- [ ] DR-21: conduct a bounded shadow evaluation before assisted use, measuring omissions, corrections, workload and escalation reliability; record who made all clinical/legal decisions.
- [ ] DR-22: evaluate action completion, actual effects, balancing harms and patient/family relevance over a defined follow-up; do not infer improved outcomes from a well-written report.
- [ ] DR-23: pursue beyond-frontier hypotheses only after earlier gates: temporally constrained evidence graphs, uncertainty-aware evidence acquisition and prospective learning-effectiveness comparison. Keep claims proportional to results.
- [ ] Checkpoint: final agent engineering review, actual evidence reconciliation and operational scope handoff; publish only artefacts whose disclosure is authorised.

## Execution and rollback

Parallelise source reconciliation and synthetic contract work; integrate changes through one owner. Do not duplicate Track 12 studies or Track 13 infrastructure. Revert a guidance/contract change through a normal reviewable commit; retain source history and failed evaluations. If a source becomes stale, disable the affected route-specific recommendation while keeping independent qualified extraction available. If an optional model/modality fails, fall back to the last qualified evidence packet and explicit unanswered questions.
