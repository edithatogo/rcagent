# Track 05 fit-gap and dependency receipt

## Decision

Adopt existing JSON Schema and pytest contracts for the deterministic core. Keep Inspect AI 0.3.260 as the primary future model-runner candidate, LM Evaluation Harness 0.4.12 as a standard-benchmark bridge, MLflow 3.15.2 as optional local lineage, and Ragas 0.4.3 as optional retrieval diagnostics. None of those four is installed or supported by this checkpoint.

The project owns only synthetic healthcare incident cases, evidence and authority rubrics, privacy and safety hard gates, jurisdiction activation boundaries, compact receipts, and thin adapters. It does not recreate a model-provider abstraction, trace store, benchmark catalogue, or results viewer.

## Evidence and boundaries

- PyPI and upstream GitHub metadata were observed on 2026-08-29; versions are discovery snapshots, not compatibility claims.
- The portable core has no runtime dependencies. The locked validation environment supplies pytest and jsonschema.
- The deterministic runner is local, network-disabled, telemetry-free, and uses synthetic fixtures only.
- The NSW policy-drift case was initially non-runnable while decision `20260829-001-active-under-review-pd2020-047` was pending. Track 04 later approved bounded active-under-review use without changing the source status; the comparator pilot included the synthetic case while preserving abstention and non-promotion.
- No real case, restricted dataset, clinical gold standard, operational acceptance threshold, or publication is admitted. A later bounded local comparator pilot used only synthetic fixtures and no external inference.

## Lifecycle

Optional adapters must pin an exact revision, disclose providers, telemetry, cache, credentials and egress, pass contract and privacy tests, and retain canonical JSON export. Removal leaves the deterministic runner and historical receipts intact. A generic upstream defect may be reported only with separate external-communication authority; any temporary local shim must name its upstream reference and expiry condition.
