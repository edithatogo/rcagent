# Context Packs

A context pack is a bounded, task-specific map to authoritative material. It is not a copy of the whole repository.

Create one from [template.md](./template.md) for each active implementation lane. Keep it current, source-linked, privacy-safe, and small enough for a fresh-context agent to reason over reliably.

Context packs may summarise sources, but the underlying source, revision, and evidence remain authoritative.

Current programme: [frontier assurance](./frontier-assurance.md) and [cognitive autopsy](./cognitive-autopsy.md). Refresh task state and exact revision before handoff; load only the current component and its dependencies.
