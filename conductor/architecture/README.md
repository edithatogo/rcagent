# Architecture Decision Records

Architecture Decision Records explain durable technical choices that affect multiple tracks or future maintainers.

## Principles

- Prefer maintained frameworks behind thin project contracts.
- Record exact alternatives, evidence, device and privacy constraints, maintenance burden, and removal path.
- Experimental adoption is not a permanent decision.
- An ADR does not override an owner decision gate or product safeguard.

## Naming

`NNNN-short-title.md`

Use [template.md](./template.md). Accepted ADRs must link validation and rollback evidence.
