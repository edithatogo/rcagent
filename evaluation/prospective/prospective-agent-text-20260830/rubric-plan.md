# Prospective rubric planning reference

This pinned planning document is not a frozen scoring protocol. The existing
[agent research rubric](../../benchmark/agent-panel-rubric.md) supplies the
candidate criteria, independent agent submissions, post-submission adjudication
and conservative non-operational thresholds. Before scoring, freeze its exact
bytes, instructions, blinding method, reviewers and conflict handling in a
new protocol version. This reference does not transitively pin that document.

The planning cases are public and visible to implementation/review agents;
they are not held-out evaluation material. Two cases and one unassigned local
text condition describe a minimal planning denominator, not a powered study,
general capability claim, model recommendation or human-comparator experiment.
No scores, agreement or performance results may be produced by this inventory.
