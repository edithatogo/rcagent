# Support and Security Boundary

This project is maintained on a best-effort basis. Public issue reports may be
made through the repository issue tracker. Do not include patient, consumer,
employee, credential, confidential, or organisation-sensitive information in
an issue, log, screenshot, fixture, or reproduction.

Security-sensitive reports should use the repository's private security
reporting channel when available. Publication, installation, validation, or a
passing test does not create a clinical, legal, policy, regulatory,
employment, organisational, deployment, availability, or response-time
commitment.

Supported public release artefacts are limited to the exact versions and
checksums named in their release receipts. Client platforms, marketplaces,
models, external services, and organisation-specific integrations remain
outside this project's support boundary unless an exact receipt says
otherwise.
